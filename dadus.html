DEMONSTRASAUN PROJETU (REZULTADU) 5.1 Menu Booking Ticket Menu ida-ne'e mak interface principal ne'ebé fó oportunidade ba utilizadór atu hahú prosesu booking ticket. Iha menu ida-ne'e, utilizadór bele asesu ba prosesu hili kadeira, prense dadus pasajeiru, haree dadus pasajeiru, no kansela rezervasaun. Prosesu booking hahú bainhira utilizadór hili menu Booking Ticket. Depois ne'e, sistema sei lori utilizadór ba menu Hili Kadeira atu hili kadeira ne'ebé disponível. 5.2 Menu Hili Kadeira Menu Hili Kadeira uza atu hatudu lista kadeira sira ne'ebé disponivel iha transportasaun. Utilizadór bele hili kadeira tuir nia hakarak. Ezemplu, utilizadór hili Kadeira A1. Bainhira kadeira A1 hili ona, sistema sei lori utilizadór ba pájina Detallu Pasajeirus, atu prense dadus identidade. 5.3 Menu Detallu Pasajeirus Menu Detallu Pasajeirus mak parte ne'ebé utilizadór tenke prense informasaun kona-ba pasajeiru. Dadus ne'ebé bele prense inklui naran, númeru pasaporte, númeru telefone, no informasaun relevante seluk. Depois utilizadór prense dadus hotu ona, utilizadór tenke klik Kontinua. Sistema sei verifika dadus no lori utilizadór ba menu Rezumu de Rezerva. 5.4 Menu Rezumu de Rezerva Menu Rezumu de Rezerva hatudu fali informasaun rezervasaun antes sistema rai dadus. Iha menu ida-ne'e, utilizadór bele haree kadeira no dadus pasajeiru ne'ebé prense ona. Se dadus hotu loos, utilizadór bele klik Rai Dados. Sistema sei rai dadus rezervasaun no dadus pasajeiru ba database. Se utilizadór klik Sai, sistema sei fila fali ba menu principal ka menu Hili Kadeira. 5.5 Menu Hare Dadus Pasajeirus Menu Hare Dadus Pasajeirus uza atu haree fila fali dadus pasajeiru ne'ebé rai ona iha sistema. Depois utilizadór asesu ba menu ida-ne'e, sistema sei hatudu lista dadus pasajeiru no informasaun rezervasaun hanesan: Naran pasajeiru Númeru pasaporte Númeru telefone Kadeira Status rezervasaun Bainhira utilizadór klik Fila, sistema sei lori fila fali ba menu principal. 5.6 Menu Kansela Dadus Menu Kansela Dadus uza atu kansela rezervasaun bainhira utilizadór lakohi kontinua ho booking ticket. Primeiru, utilizadór tenke asesu ba menu Kansela. Sistema sei hatudu lista kadeira ne'ebé iha rezervasaun. Ezemplu, utilizadór hili Kadeira A1. Depois sistema sei husu númeru pasaporte atu konfirma katak rezervasaun ne'e pertense ba pasajeiru ne'ebé loos. Depois prense númeru pasaporte, utilizadór klik Kansela Reservadu. Sistema sei hatudu mensajen konfirmasaun. Utilizadór klik OK atu kontinua prosesu kanselamentu. Depois kansela ho susesu, status kadeira sei muda husi Rezervadu ba Disponível, no kadeira ne'e bele uza fali ba booking seluk.
